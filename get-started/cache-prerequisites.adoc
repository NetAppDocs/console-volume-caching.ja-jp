= NetApp Volume Cachingの前提条件
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
まず、運用環境、ログイン、ネットワーク アクセス、Web ブラウザーの準備状況を確認します。

ボリューム キャッシュを使用するには、環境がすべての要件を満たしていることを確認する必要があります。

* ONTAP 9.8以降
+
** クラスタ管理者ONTAP権限
** クラスタ上のクラスタ間LIF


* NetApp Consoleの場合:
+
** Consoleエージェントは、NetApp Consoleでセットアップする必要があります。すべてのソースクラスタとターゲットクラスタは、同じConsoleエージェント上にある必要があります。link:https://docs.netapp.com/us-en/console-setup-admin/task-quick-start-standard-mode.html["NetApp Console の使用開始ワークフロー"^]およびlink:https://docs.netapp.com/us-en/console-setup-admin/concept-agents.html["コンソールエージェントについて学ぶ"^]を参照してください。
** 作業環境を整える必要があります。
** クラスターは、ターゲットの作業環境にオンまたは低下した状態で追加する必要があります。
** 標準的なNetApp Consoleの要件。参照 https://docs.netapp.com/us-en/cloud-manager-setup-admin/reference-checklist-cm.html["NetApp Consoleの要件"^]。
